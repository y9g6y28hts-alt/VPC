# Logo de Da Silva Automotores

Coloque aquí el archivo ORIGINAL del logotipo (emblema circular rojo con
tipografía blanca), sin modificarlo:

- `logo.svg` (preferido), o
- `logo.png` / `logo.webp` con fondo transparente, al menos 512 px de ancho.

La aplicación lo detecta automáticamente al iniciar y lo usa en la barra
lateral, la pantalla de ingreso y las propuestas PDF. Mientras el archivo no
exista se muestra el nombre de la empresa en texto: no se genera ningún logo
sustituto.

Después de incorporarlo, calibre `--color-brand` en `src/app/globals.css`
con el rojo exacto del emblema (hoy es un valor provisional).
